A mod that synchronizes mods between the client and server, and must be loaded on both the server and client. For Minecraft 1.20.1 Fabric.

On the server, you can copy any mods that do not need to be synchronized into Jane\blacklist in the server root directory. Jane will skip them during synchronization. If this folder does not exist, you can create it yourself or start the server once.

Generally, the mods used to fill in missing ones come from Modrinth. If Jane cannot find a mod on Modrinth, you can choose to download it from the connected server. Of course, you can also choose not to synchronize these mods and join the server directly.
[Whether you'll actually be able to join is another story.]
